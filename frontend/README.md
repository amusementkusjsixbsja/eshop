# 前端 (frontend)

React + Vite + TypeScript 电商平台前端。

## 技术栈

- React 19 + TypeScript
- Vite 6（开发服务器 + 构建）
- React Router 7（客户端路由）
- Axios（HTTP 客户端）
- react-markdown（AI 对话 Markdown 渲染）

## 设计系统

- **主题**：白色 (#FFFFFF) + 翡翠绿 (#059669)
- **标题字体**：DM Serif Display（衬线，优雅）
- **正文字体**：DM Sans（无衬线，清晰）
- **点缀色**：琥珀 (#F59E0B)、玫瑰 (#F43F5E)
- **CSS 变量**：统一色板、间距、圆角、阴影、动画

> 注意：前端通过 Nginx 代理 API 请求，开发时 Vite 代理到 `localhost:80`。

## 页面列表

### 公开页面

| 路由 | 页面 | 说明 |
|------|------|------|
| `/products` | 商品列表 | 分类筛癣关键词搜索、热门推荐横幅、商品网格 |
| `/products/:id` | 商品详情 | 商品图、信息、数量选择器、加入购物车 |
| `/login` | 登录 | 邮箱 + 密码，登录后跳转对应页面 |
| `/register` | 注册 | 邮箱 + 密码 + 昵称 |

### 用户页面（需登录）

| 路由 | 页面 | 说明 |
|------|------|------|
| `/cart` | 购物车 | 商品列表、数量控制、地址选择器、合计结算 |
| `/orders` | 订单列表 | 按状态筛癣每个订单可点进详情 |
| `/orders/:id` | 订单详情 | 状态、商品明细、支付/取消操作、物流入口 |
| `/logistics/:orderId` | 物流追踪 | 承运信息、时间线节点展示 |
| `/after-sales` | 售后中心 | 申请表单、历史记录 |
| `/addresses` | 地址管理 | 多地址 CRUD、默认地址切换 |

### 管理页面（需 admin 角色）

| 路由 | 页面 | 说明 |
|------|------|------|
| `/admin/categories` | 分类管理 | 分类增删改、层级展示 |
| `/admin/products` | 商品管理 | 商品列表、上下架操作 |
| `/admin/orders` | 订单管理 | 全平台订单、状态筛癣按用户筛选 |

### 通用组件

- **AI 客服浮窗** — 所有页面右下角，流式对话，支持工具调用查询订单/物流/商品
- **导航栏** — 自适应：游客 → 前台；用户 → 购物车/订单/地址/售后；管理员 → 管理后台
- **空状态**、**加载骨架**、**错误提示**

## AI 客服接口

| 端点 | 说明 |
|------|------|
| `POST /api/ai/chat/stream` | 流式 SSE，工具调用完成后逐 token 输出 |
| `POST /api/ai/chat` | 非流式，完整回复 |

认证：自动附加 `Bearer <token>`。

## 构建

```bash
npm install
npm run dev      # 开发（热重载，端口 5173）
npm run build    # 生产构建 → dist/
```
