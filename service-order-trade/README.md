# 购物车与交易服务 (service-order-trade)

购物车、订单、物流、售后、定时任务 — 由 小C 负责。

## 端口

- 外部：`8002`
- 内部：`order-trade:8002`

## 功能模块

### 1. 购物车（`/c-endpoint/cart`）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/` | 查看购物车（JOIN 商品表） |
| POST | `/` | 添加商品（UPSERT 幂等叠加数量） |
| PUT | `/{product_id}` | 修改数量 |
| DELETE | `/{product_id}` | 删除购物车项 |

### 2. 订单（`/c-endpoint/orders`）

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/` | 创建订单（事务：锁库存 → 扣减 → 插订单 → 清购物车） |
| GET | `/` | 订单列表（支持 status 筛癣分页） |
| GET | `/{id}` | 订单详情（含商品明细 JOIN） |
| POST | `/{id}/pay` | 支付（FOR UPDATE 幂等校验 + 创建物流 + 支付记录） |
| POST | `/{id}/cancel` | 取消（FOR UPDATE + 回滚库存） |

### 3. 物流（`/c-endpoint/logistics`）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/{order_id}` | 查询物流（校验订单归属） |

### 4. 售后（`/c-endpoint/after-sales`）

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/` | 提交售后申请（退款/退货/换货） |
| GET | `/` | 售后申请列表 |

### 5. 内部接口（`/internal` — 供 AI 客服调用）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/orders` | 查询用户订单列表 |
| GET | `/orders/{id}` | 订单详情 |
| GET | `/logistics` | 查询物流信息 |
| GET | `/after-sales` | 查询售后申请 |

### 6. 定时任务（APScheduler）

| 任务 | 周期 | 说明 |
|------|------|------|
| 超时取消订单 | 每 5 分钟 | Redis 分布式锁，逐条 FOR UPDATE + 回滚库存 |
| 物流状态推进 | 每 30 秒 | 5分钟极速配送，每分钟推进一个节点 |

## 5分钟极速物流

支付下单后，物流每 1 分钟自动推进一个节点：

```
支付成功 → 已揽件 @ 深圳仓库          (0分钟)
         → 运输中 @ 深圳集散中心       (1分钟)
         → 运输中 @ 广州中转           (2分钟)
         → 派送中 @ 派送中             (3分钟)
         → 已签收 @ 您的手中           (5分钟)
```

## 技术要点

- 手动事务管理（`autocommit=False`）
- `SELECT ... FOR UPDATE` 行级锁防止超卖
- 订单创建、支付、取消均为独立事务，失败全回滚
- Redis 分布式锁保障定时任务单实例执行
- 每单独立事务，一单失败不影响其他订单
